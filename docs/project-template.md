# 项目说明模板

> 每做完一个值得写的项目，就把本文件复制一份，命名为 `docs/项目/<项目名>.md`，按下面的空填。
> 然后到 `projects.html` 里复制一个 `<div class="project">…</div>` 块，把文字同步过去。
>
> 项目说明是给**面试官看的材料**，不是给老师交的作业。所以：
> 写你**真做的事**，写清楚**难点和怎么解决的**，写**结果**（能量化就量化）。

---

## 项目名称

- 类型：课程作业 / 比赛 / 个人练习 / 实习
- 时间：YYYY.MM — YYYY.MM
- 参与人数：个人 / 几人团队（我负责：___）
- 状态：已完成 / 进行中 / 已停更
- 代码仓库：（有就填链接，注意把仓库设为公开）
- 在线地址：（有就填）

## 一句话介绍

> 用一句话说清楚：给谁做的、解决什么问题、怎么解决的。
>
> 例：为学院社团做的活动报名网页，把原来在群里接龙的报名方式换成在线表单，报名人数从 30 人提升到 90 人。

## 背景

为什么要做这个项目？原来的方式有什么问题？
