## 二、课程（`courses.html`）

- [ ] **6. 核对课程表** —— 打开学校教务系统 → 我的课表 / 成绩，对照表格核对：
  - 课程名称是否一致（表格里的课程是按培养方案**预估**的）；
  - 课程类型（专业必修 / 公共必修 / 专业选修…）；
  - 学分；
  - 成绩：出了成绩就把「待补充 / 待出」改成分数，没出就保留「待出」。
- [ ] **7. 增删课程** —— 删掉没开过的课；有课表上没写的课（如形势与政策、军训）可以补上。
  **不要写没上过的课**，面试时被问到答不上来比少写一门更尴尬。

分数填写示例（注意同时改样式）：


| 项目 | 需要补充的内容 |

### 写项目的公式

> 我在 **什么背景下**，负责 **什么**，用了 **什么方法/技术**，**解决了什么问题**，结果 **怎样**。

反例：*做了一个管理系统，学会了增删改查。*
正例：*为了统计班里同学的四级报名信息，用 C 语言写了命令行报名程序，用文件保存数据，替代了原来的纸质表格。*
