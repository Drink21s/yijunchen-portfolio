## 1. 项目背景

学校要求制作一个个人介绍网站。这个项目有两个目的：

1. **教学目的**：掌握静态网页制作、Git 版本管理、云服务器部署；
2. **长期目的**：这个网站会一直用到**大四毕业找工作**，所以不能只是“交上去就完事”的兴趣主页，
   而要是能拿给 HR 和面试官看的**求职作品集**。

考虑到本人开发经验有限，项目在**已有的一个 AI 生成的个人主页**基础上做**改造**，
而不是从零重写——先把结构理顺，再把每一页写好，这样既能保证按时交出作业，也能真正学懂每一段代码。

### 2.2 求职场景的需求

面试前，HR 通常只看 **30 秒**。因此页面的信息优先级是：

1. 是谁：姓名、学校、专业、年级 → 首页第一屏；
2. 会什么：技能、获奖 → 首页第二屏；
3. 做过什么：项目经历 → `projects.html`；
4. 学过什么：课程 → `courses.html`；
5. 怎么联系：邮箱 / 电话 / PDF 简历 → 每一页底部 + `contact.html`。

> 健身、骑行、猫这些内容保留，是因为它们能让一个“没有实习经历的学生”的简历变得真实、有记忆点；
> 但它们放在「生活」菜单里，不占用首页最重要的位置。

## 3. 设计说明

### 3.1 视觉风格（沿用原版，没有推翻重来）

| 设计元素 | 取值 | 说明 |
| --- | --- | --- |
| 底色 | `#faf6f1` 暖白 | 像纸一样的背景，比纯白柔和，长时间看不累 |
| 主文字 | `#171512` 近黑 | 对比度足够，阅读清晰 |
| 强调色 | `#ff8f45` 橘 | 只用在标签、按钮、进度条、序号上，避免花哨 |
| 字体 | 系统无衬线（苹方 / 微软雅黑） | 不加载外部字体，打开更快 |
| 标题 | 超大字重 + 描边字 | 保留原版的“大标题 + 空心副标题”风格 |
| 装饰 | 极淡的纸感颗粒 `.grain` | 原版就有，保留以保持统一 |

### 3.2 简历化的版式

- **首屏三件套**：左边是求职定位 + 联系方式，右边是证件照卡，下面是一屏速览（学校 / 专业 / 获奖 / 作品）。
- **左右分栏简历**：每一节用 `220px 侧栏 + 内容区`，侧栏写章节名并随滚动吸顶，像一份真正的简历。
- **项目卡**：左边是时间 / 类型 / 状态，右边是“做了什么 → 怎么做 → 结果”，符合写简历的习惯。
- **打印样式**：`@media print` 里隐藏导航、字幕、按钮、装饰，把配色改成黑白，字号缩小，
  这样 `Ctrl + P` 就能直接得到一份 PDF 简历。

### 3.3 响应式断点

| 屏幕宽度 | 行为 |
| --- | --- |
| > 900px | 三栏 / 双栏网格 |
| ≤ 900px | 卡片单列 |
| ≤ 820px | 简历侧栏移到上方；速览数据条变两列 |
| ≤ 780px | 导航改为可横向滚动，下拉菜单靠左对齐 |
| ≤ 520px | 速览数据条单列 |

## 4. 技术实现

### 4.1 目录与文件职责

| 文件 | 行数（约） | 职责 |
| --- | --- | --- |
| `assets/style.css` | 510 | 全站样式：变量、布局、组件、响应式、打印 |
| `assets/main.js` | 208 | 全站脚本：导航、淡入、动画、筛选排序、打印 |
| `*.html` | 每页 50–280 | 内容（结构），不含样式和逻辑 |

### 4.2 关键技术点

**① CSS 变量做主题**
所有颜色、圆角、间距都在 `:root` 里定义，改一行 `--accent` 就能换掉全站主题色。

```css
:root{
  --bg:#faf6f1;
  --accent:#ff8f45;   /* 换颜色只要改这里 */
  --radius:22px;
}
```

**② 流式字号**
用 `clamp(最小值, 视口比例, 最大值)` 让标题在手机上不溢出、在大屏上够大气：

```css
.display{ font-size:clamp(3rem,12vw,9rem); }
```

**③ CSS Grid 布局**
简历分栏、卡片网格、项目卡都使用 Grid，比浮动和 Flex 嵌套更好维护：

```css
.resume{ display:grid; grid-template-columns:220px 1fr; gap:48px; }
```

**④ 导航统一渲染**
10 个页面如果每个都写一遍导航，加一个页面就要改 10 次。做法是：

- HTML 里先写一份“不会闪”的基础导航（即使用户禁用了 JS 也能点）；
- `main.js` 的 `renderNav()` 在页面加载后把它替换成完整导航（含「生活」下拉）；
- 根据当前文件名自动加 `active` 高亮。

**⑤ IntersectionObserver 做滚动动画**
元素进入视口才加 `.in` 类触发淡入；技能条也是进入视口后才从 0 增长到目标宽度，避免用户没看到就已经播完。

**⑥ 课程表筛选与排序（原生 JS）**
- 每行课程有 `data-term="2025-1"`，按钮点击时给不匹配的行加 `.is-hidden`，纯 CSS 隐藏；
- 点表头读取 `data-col`，取出对应单元格文字，数字按数值比较、文字按 `localeCompare('zh-Hans-CN')` 比较，再重新 `appendChild` 排序；
- 排序只对**当前可见**的行生效，所以先筛选再排序不会把隐藏的行弄乱。

**⑦ 打印样式**
`@media print` 中隐藏 `.site-header`、`.marquee`、`.cta`、按钮等；
把彩色区块改成白底黑字；技能条用 `width:var(--v)!important` 强制展开（否则动画没触发时会显示空条）。

**⑧ 图片缺失容错**
照片还没放进 `assets/photos/` 时，`<img>` 的 `error` 事件会给外层 `.photo` 加 `.missing`，
显示“请把照片放这里”的虚线框，而不是浏览器的破图图标。

### 4.3 兼容性

- JavaScript 主要使用 ES5 语法（`var`、`function`、`forEach`），不使用可选链等新特性，
  保证老版本浏览器与旧手机也能运行；只有课程筛选那一处用了 `closest()`（现代浏览器全部支持）；
- `IntersectionObserver` 不支持时自动退化为“全部直接显示”；
- 关键内容（导航、正文）都在 HTML 里，不依赖 JS 渲染，禁用 JS 后依然可读。

## 5. 我如何理解这份代码（答辩准备）

> 老师可能会问“这段是不是 AI 写的”。老实回答：初版由 AI 生成，改造由自己和 AI 一起完成；
> 但下面这些问题要能自己讲清楚。

1. **为什么不用框架（Vue / React）？**
   本项目只有 10 个静态页面，没有数据交互，引入框架反而增加体积和构建步骤。
   纯手写能让每一行都看得懂，也直接满足“纯静态页”的要求。
2. **`body` 为什么要先透明再显示？**
   `body{opacity:0}` + `.ready{opacity:1}` 是页面淡入效果；`<noscript>` 里重新设为 1，
   防止用户禁用 JS 后整页空白。
3. **为什么导航要在 JS 里再渲染一次？**
   为了“一处修改，全站生效”。HTML 里的那份是给没有 JS 的用户和首屏加载用的。
4. **`clamp()` 和媒体查询有什么区别？**
   媒体查询是按断点一次性切换（阶跃变化），`clamp()` 是随屏幕宽度连续变化（流式变化），
   两者结合既有细腻的字号变化，又有布局上的切换。
5. **排序时为什么不用 `innerHTML` 重建表格？**
   `appendChild` 移动已有节点，不重新解析 HTML，更快，也不会丢失事件绑定和 `data-*` 属性。
6. **部署时为什么要把 `.git` 目录藏起来？**
   如果直接把整个项目目录放进网站根目录，别人访问 `/.git/config` 就能拿到仓库信息，
   甚至可能被还原出源码历史。Nginx 配置中 `location ~ /\. { deny all; }` 就是用来防这个的。
7. **为什么 Nginx 里用 `try_files $uri $uri/ =404;`？**
   纯静态站点不需要“单页应用回退到 index.html”，找不到文件就应该返回 404，
   否则任何错误链接都会显示首页，搜索引擎会认为网站有大量重复页面。

- **做成了什么**：一个可以公网访问、能导出 PDF、能持续更新到大四的个人网站。
