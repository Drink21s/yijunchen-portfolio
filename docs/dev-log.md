## v1.1.0 — 2026.11.17 — 修复导航、统一口径、接入 Git

**目标**：把上一版遗留的三个“点了没反应”的导航问题修掉，把年级与技能口径统一成 2024 级大三，
并把项目正式纳入 Git 管理（此前只有 `.gitignore`，没有仓库）。

### 问题与修复

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 点右上角「证书」没反应 | `main.js` 里写成 `courses.html#certificates`，但 `courses.html` 里没有这个锚点，只会跳回课程页顶部 | 改为指向真实页面 `certificates.html` |
| 点右上角「生活」没反应 | `.site-nav` 上有 `overflow-x:auto`，导航成了滚动容器，而 `.nav-menu` 是绝对定位子元素，被裁到导航条那一行高度里 | 去掉 `overflow`，改 `flex-wrap:wrap`；窄屏 media query 补 `justify-content:flex-start` |
| 各页导航顺序不一致 | 11 个页面里存在两套静态导航写法（一套含「生活」下拉，一套是「关于我/健身/骑行/设计/猫咪」平铺） | 用脚本统一成与 `renderNav()` 输出一致的一份 |

### 内容口径

| --- | --- |

### 设计决策

1. **不重新做网站，只在原基础上改**
   原版配色（暖白 + 橘）、字体、纸感颗粒、滚动字幕、大标题风格全部保留；
   新组件都沿用 `--accent` 等 CSS 变量，保证风格统一。
2. **导航用 JS 统一渲染，而不是改 10 个 HTML 文件**
   原来首页和子页的导航不一样；如果逐个手改，以后加页面要改 10 次。
   现在每页 HTML 里留一份基础导航（无 JS 也能用），`main.js` 再替换成完整版。
3. **把“生活”类内容收进下拉菜单**
   健身、骑行、猫保留，但不再和项目、课程抢首页位置。
4. **PDF 简历不单独做一份**
   直接给首页写 `@media print` 样式，`Ctrl + P` 就是 PDF。
   好处：改了网站内容，PDF 自动同步，不会出现“网站改了、简历忘改”。
5. **所有占位都明确写“待补充”**
   宁可写得少，也不要编造成绩和奖项。

### 遇到的问题

| 问题 | 原因 | 解决 |
| --- | --- | --- |
| Git 第一次提交后所有文件显示“已修改” | Windows 的 `core.autocrlf` 把 LF 换成 CRLF | 仓库内设置 `core.autocrlf=false`，并用 `.gitattributes` 指定换行符 |
| 在 `.gitattributes` 前提交会产生大量无意义差异 | 同上 | `git rm -r --cached .` 后重新 add，再 amend 第一次提交 |
| 打印时技能条是空的 | 技能条宽度靠滚动动画设置，打印预览不会触发动画 | 打印样式里强制 `width:var(--v)` |
| 打印时整页被 `break-inside:avoid` 挤成一页 | 规则写在了 `section` 上 | 改为只对卡片、项目、时间线条目生效 |
| 证书扫描件整张卡片放进去太挤 | 证书卡是纵向布局 | 新增 `.photo.card-photo` 小图样式 |
| 文档文件名带中文，以后传到服务器、贴到 URL 里容易乱码 | 中文文件名在 Git 输出里会显示成 `\346\226\207\344\273\266` | 文档文件名统一改成英文（如 `deployment-guide.md`），**内容仍保持中文** |
