# 照片目录说明

把照片放在这个文件夹里，文件名要和下面**完全一致**（区分大小写，后缀用小写 `.jpg`）。
没有放照片的位置会显示一个虚线提示框，不会破图，也不影响其他内容。

> 注意：这里只写文件名即可，**不要把电脑上的完整路径写进来**。
> 真正要做的是把图片文件本身复制进这个文件夹，并改名成下表的名字。

## 拍摄与处理建议

- 横图最好，长边 **1600 像素**左右就够了，单张控制在 **500 KB** 以内；
- 竖图会从中间偏上裁切，证件照正好适合竖图；
- 手机原图太大，可以先用 <https://tinypng.com> 压缩，或在 Windows「照片」里"调整大小"。

## ⚠ 隐私提醒

这个网站是公开的，任何人都能下载上面的图片。上传前请检查：

- 身份证号、学号、家庭住址、门牌号；
- 车牌、快递单、二维码（可能包含手机号）；
- 证书上的身份证号、出生日期等，**先打码再上传**。
