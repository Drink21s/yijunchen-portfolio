关于我

一个把时间分成三份的人：一份给代码和设计，一份给铁和路，剩下的给音乐和自由。

我是谁

我叫易俊臣，现在在四川传媒学院读计算机科学与技术，属于智慧广电学院，2024 级大三。

C 语言、数据结构、Web 前端这三样是我最拿得出手的：C 语言能写完整的课程设计， 数据结构与算法能自己分析、动手实现，前端能纯手写 HTML / CSS / JavaScript 做响应式页面。 这个网站就是我自己写的——从一行行 HTML，到用 Git 提交，再到把它放到服务器上。

同时我也有广告设计和建模的底子：一张海报怎么让人多看两秒，一个模型怎么把脑子里的东西摆出来， 这些我做了不少，也拿过全国大学生广告艺术大赛一等奖。技术和设计同时会一点， 是我现在最实际的优势。

我喜欢自由。不喜欢被框着，也不喜欢做一件事只是为了完成它。 健身和骑车也是这样——没人逼我，但这两件事我一直在做，一路骑到成都绿道的最快纪录是 2 小时 51 分。
